1 · Command Center

A classic three-column layout, like an IDE. Left: repo list, filters and the depth switch (repo, project or endpoint). Center: the graph. Right: an inspector for whatever is selected, showing callers, versions and endpoints. Everything stays visible, which suits long sessions exploring the system.

It's the most striking layout and the closest match to the Observatory feel, and it stays clean while you explore.

3 · Explorer + Data Drawer

The graph sits on top, with a browser-DevTools-style drawer of sortable tables underneath: callers, endpoints, version drift and unresolved links. Clicking a row highlights it in the graph, and selecting a node filters the tables. This is the best layout for audits and answering questions like "which consumers are behind on versions?".
