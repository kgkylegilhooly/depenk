B · Payload flow, with models on the canvas

The canvas shows request going out and response coming back as two animated lanes. Beneath them the model graph expands as linked cards, with fields listed inline and types from other repos highlighted in amber. Selecting a model shows every endpoint and repo it passes through. This version shows data flowing most literally, but the canvas gets busier.

Both versions let you get there from either side: Endpoints tab (endpoint → models) or Models tab (model → every endpoint and repo that uses it). Everything on screen is also available through MCP.
